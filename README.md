# DroneControll

El archivo de python esta dentro de la carpeta script, al iniciar el archivo se tiene que escribir la ip del equipo donde se aloje desde el comando (python dron.py 192.168.1.5), al iniciar dira la informacion que tendras q  ue poner en la escena de unity, la ip y los puertos de video y para controlar el dron, y simplemente le das a play.

Ahora mismo no tiene compatibilidad absoluta con mando, seguramente se podra mover, despejar y aterrizar, rotar y subir/bajar todavia no.

# Controles

WASD: mover el dron w/s: delante/atras a/d: Izquierda/derecha

flecha Arriba/abajo: Subir o bajar el dron

flecha Izquierda/Derecha: Rotar el dron

T: Despejar el dron

L: Aterrizar el dron
